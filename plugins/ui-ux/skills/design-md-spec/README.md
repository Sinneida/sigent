# design-md-spec

> Semantic version: `0.2.3`

Skill for creating, applying, and generating `DESIGN.md` design-system specifications following the [google-labs-code/design.md](https://github.com/google-labs-code/design.md) format.

## Capabilities

- **Generate** a `DESIGN.md` from a screenshot or browser page read by the agent
- **Apply** an existing `DESIGN.md` to a new or existing project (Tailwind, CSS, SCSS)
- **Create** a new `DESIGN.md` from scratch via guided interview
- **Review** an existing `DESIGN.md` for completeness and token validity
